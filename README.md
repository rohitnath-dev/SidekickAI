# SidekickAI

SidekickAI is an AI-powered executive assistant designed to help users manage their communications, understand what needs attention, and turn incoming information into useful actions and insights.

## Live Application

https://sidekickai-1.onrender.com/

## What SidekickAI Does

SidekickAI brings information from connected services into one place and uses AI to help make sense of it.

The application is designed around a simple idea:

> Spend less time processing information and more time acting on what actually matters.

### Current Capabilities

- Synchronize communications from connected services
- Analyze incoming communications with AI
- Generate an executive daily briefing
- Identify important risks, priorities, deadlines and work items
- Suggest useful next actions
- Generate suggested reply drafts
- Provide an executive inbox for synchronized communications
- Manage connected integrations
- Run AI processing in the background
- Provide an Auto Pilot interface for future background automation

## Executive Dashboard

The dashboard provides a high-level view of the user's current information and activity.

It includes areas such as:

- AI Daily Executive Briefing
- Critical Risks & Blocks
- Recommended Focus Areas
- Upcoming Milestones & Deadlines
- Suggested Next Actions
- Pending Work Items
- Proactive Action Queue

## Executive Inbox

The Executive Inbox provides a centralized view of synchronized communications.

Users can search and filter communications and review AI-generated information and suggested actions associated with individual messages.

## AI Briefing

SidekickAI can process synchronized communications and generate an executive briefing that summarizes the information that requires attention.

The briefing is intended to help users quickly understand:

- What matters
- What requires attention
- What should be prioritized
- What actions may be useful

## Proactive Actions

SidekickAI can identify communications that may require a response and present them in a proactive action queue.

Where supported, the system can generate a suggested reply that the user can review before taking action.

## Integrations

SidekickAI uses connected third-party services to synchronize relevant information.

The application currently includes integration support for services used for communication and productivity workflows. Available integrations depend on the configuration of the deployed application and the permissions granted by the user.

## Privacy & Security

SidekickAI requires authorization to access data from connected services.

Users should only connect accounts and services they are comfortable authorizing.
